# 能力金字塔分层框架（模型测评视频核心方法论）

> 从 DeepSeek V4 Pro vs Flash 实测视频（2026-08）四版大纲迭代中沉淀。教训：按"任务类型"分关（聊天/写码/修 bug）会让能力维度含糊；按"能力维度"分关，观众能清楚复述"强在哪、够用在哪"。

## 一、六层能力金字塔

| 层级 | 能力 | 定义 | 典型 benchmark 锚点 | 典型测试形式 |
|---|---|---|---|---|
| L1 | 语言能力 | 理解、生成、表达、摘要、改写 | MMLU / MMLU-Pro（Non-think 档）、CMMLU | 文案改写、长文摘要、盲评 |
| L2 | 知识能力 | 世界知识储备量（参数规模的护城河） | SimpleQA(-Verified)、TriviaQA、FACTS | 冷门事实问答、专业知识问答 |
| L3 | 推理能力 | 数学/科学多步逻辑推演（思考模式的最大受益者） | GPQA Diamond、HLE、HMMT、AIME | 奥赛级数学题、多步逻辑题 |
| L4 | 代码工程能力 | 代码生成 + 真实仓库级修复 | LiveCodeBench、SWE-bench Verified、HumanEval、Codeforces | 从 0 写小工具、真实项目修 bug |
| L5 | 长上下文能力 | 长文档检索（找针）+ 跨章多跳推理 | MRCR 1M、CorpusQA、LongBench | 百万字文档找针、整库代码问答 |
| L6 | 智能体能力 | 规划 + 工具调用 + 错误自愈（前五层综合大考） | Terminal Bench、SWE-bench 多语言、Toolathlon、BrowseComp | 终端排障全程无人干预、多工具编排任务 |

层级可调：多模态模型可加"视觉理解层"；垂直模型可替换为领域层（医疗/法律/金融）。但认知递进原则不变：每层依赖下层的全部能力。

## 二、分关设计原则

1. **一关一项能力**：不要"边写代码边考知识"。混搭会稀释结论，观众记不住。
2. **一关一个数字锚点**：从官方模型卡选该层最有代表性的分数，其余数字留作口播备用。
3. **差距曲线波浪形**：不要单调递增。参考实测验证过的节奏：打平(L1) → 拉开(L2) → 双翻车(L3 低档) → 紧贴(L4) → 拉开(L5) → 最大鸿沟(L6)。胶着关是先抑后扬的天然素材。
4. **名场面选差距最大层**：通常是 L6（综合能力鸿沟）或 L3（模式开关反差）。双屏对比、结果定格、留 10 秒以上。
5. **升档轴**：除任务难度外，思考模式（Non-think → High → Max）、文档长度、并发数都可作"拧高一档"的仪式感道具，画面上做成旋钮/进度条。

## 三、反常识钩子清单（实测有效）

- **模式开关**：同一模型同一道题，Non-think vs Think Max 分数差数倍（实例：HLE 7.7 → 37.7）——"差 5 倍的不是模型，是开关"
- **知识护城河**：思考模式补得齐推理，补不齐世界知识——小激活参数模型在 L2 被甩开（实例：SimpleQA 28.9 vs 46.2）
- **性价比倒挂**：塔底两层被便宜模型打成白菜价，贵模型只在塔尖值回票价
- **小模型反超**：轻量模型在某单层反超自家大模型预览版（训练效率故事）

## 四、三种模式的结构适配

- **单模型**：金字塔逐层爬，叙事问句"它爬到第几层开始吃力？"
- **双模型对决**：同题双屏 + 比分板（X:X）每关翻牌；收尾给"能力-场景-价格"选型表作 CTA 钩子
- **多模型横评**：每层只留一个擂主，金字塔变天梯榜；关数控制在 5 层以内避免超时
