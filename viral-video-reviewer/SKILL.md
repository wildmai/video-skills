# 爆款视频稿验收 Skill

## 目的

对照爆款制作规范，系统性地验收视频大纲/脚本/口播稿，找出差距并给出可直接执行的优化方案。验收不是泛泛建议，必须逐条对照检查单、定位到具体时间段/句子。

## 触发场景

- 用户说"帮我验收/评审/检查这个视频脚本/口播稿/大纲"
- 用户要求"按爆款规范找差距/给优化方案"
- viral-video-creator 产出稿件后的质量验收环节

## 规范来源（按优先级）

1. 从本技能目录读取同级技能中的 `../viral-video-creator/references/production-spec.md`。
2. 若该文件不存在，使用 `references/checklist.md` 中的内置检查单。

## 执行流程

### 第 1 步：读取被验收稿件

读取用户指定的稿件文件（大纲/脚本/口播稿，可多份）。若用户粘贴的是文本而非文件，先保存为 `review-input.md` 再验收。

### 第 2 步：逐维度打分验收

按以下 8 个维度逐项检查，每项给出 ✅通过 / ⚠️部分达标 / ❌不达标，并**引用稿件原文具体位置**（时间段或句子）作为证据：

1. **钩子系统**：首 15 秒是否结果前置？钩子链密度（每 30–60 秒一个）？标注每个钩子的位置与类型，找出"钩子真空区"（超过 60 秒无钩子的段落）。
2. **结构递进**：是否符合七段式？各段时长占比是否达标？案例链是否"后一个比前一个更厉害"？
3. **信任构建**：是否至少 1 处先抑后扬？是否有一路夸到底的广告感？
4. **记忆点**：是否有名场面？是否有 ≤30 字可截图金句？
5. **数字锚点**：是否 ≥3 个具体数字？逐个列出。
6. **节奏与画面**（如有分镜/画面说明）：任意 20 秒是否有画面变化？等待/加载画面是否清零？场景切换频率？
7. **文案禁忌**：逐项扫描禁忌清单——"大家好"、空洞自夸、无信息停顿、"然后"连用、匀速念稿迹象（句子长度过于均匀）。
8. **标题与封面**（如有）：是否符合"角色/结果 + 悬念 + 品类"公式？封面大字 ≤10 字？

### 第 3 步：输出验收报告

保存为 `<稿件所在目录>/验收报告-<日期>.md`（若输入是临时文本则存当前工作区 `review-output/` 下），结构固定：

```markdown
# 验收报告：<稿件名>
## 总体评分：X/100（各维度加权：钩子20 结构20 信任10 记忆点15 数字锚点10 节奏画面15 文案禁忌5 标题封面5）
## 一、逐项检查结果（✅/⚠️/❌ + 原文证据）
## 二、TOP 问题清单（按对爆款概率的影响排序，最多 5 个）
## 三、优化方案（每个问题给出：问题定位 → 改写前原文 → 改写后建议 → 依据的规范条款）
## 四、验收检查单勾选结果
```

优化方案必须是"改写级别"的——直接给出可用的替换文案，而不是"建议加强钩子"这种空话。

### 第 4 步：交付

用 present_files 呈现验收报告，并用 3–5 句话概括：总体评分、最严重的 1–2 个问题、修改后的预期提升点。

## 硬性规则

- 验收结论必须引用原文证据，禁止无依据的泛泛评价。
- 优化建议必须给出可直接使用的改写文案。
- 报告必须落盘保存。
- 若稿件严重不达标（<60 分），在报告开头明确建议"按 viral-video-creator 的 SOP 重写"而非修补。
