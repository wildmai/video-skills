# YouTube Viral Thumbnail Designer Skill

这是一个用于 AI / AI Coding / Agent / 技术类 YouTube 视频的爆款封面设计 Skill。

## 最小输入

只需要提供视频概要，例如：

```text
使用 youtube-viral-thumbnail-designer：
这期视频讲 CodeBuddy NPC 如何以 Git 仓库为 AI 原生记忆，融入企业已有研发流程，让 AI 从单点 Coding 工具升级成工程化协作者。直接生成 16:9 封面。
```

Skill 会自动完成：

1. 找出唯一点击钩子
2. 压缩成 4–10 字封面文案
3. 选择 A–F 构图
4. 选择唯一可信证据
5. 检查手机缩略图和 4:3 裁切
6. 有图片工具时直接生成成图
