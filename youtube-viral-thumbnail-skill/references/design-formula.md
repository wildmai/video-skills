# 爆款 YouTube 技术封面设计公式

## 一句话核心

> 封面不是视频摘要，而是“点击理由的视觉化”。

## 最优结构

> 一个强判断 + 一个强主体 + 一个可信证据 + 大量留白

## 文案

优先 4–10 个汉字、1–2 行、单一判断、单一高亮词。

不要写：

- CodeBuddy NPC 融入 Git 仓库实现企业研发流程升级

应压缩成：

- AI终于 / 进流程了

## 一级主体数量

最多两个，例如：

- 大字 + 流程图
- 人物 + 大字
- 软件界面 + 人物
- 大数字 + 真实结果

## 证据

证据的作用不是被完整阅读，而是让观众感知“这是真实案例”。

## 留白

留白让标题更大、主体更强、画面更高级。不要用装饰填满空位。

## 典型模板

### 人物型

左标题 / 右大脸 / 暗化真实背景 / 1 个小证据。

### 概念型

超大概念词 / 情绪判断 / 少量手绘草图 / 黑底。

### 流程型

强判断 / 3–7 个节点极简流程 / 强调 AI 真正嵌入流程。

### 实测型

真实软件界面 / 人物或结果 / 一句极强判断。

### 数字型

超大数字 / 结果解释 / 单一真实证据。

### 对比型

左右对抗 / 一个维度 / 一个清晰胜负或反差。

## 手机端原则

缩小后允许小字消失，但不允许核心观点消失。
