# 示例：CodeBuddy NPC

## 用户概要

让 AI 住进企业已有研发工作流，解决 AI 与研发流程割裂。CodeBuddy NPC 以 Git 仓库作为 AI 原生记忆，直接融入已有研发流程，从“单点效率工具”升级为“工程化协作者”。

## 核心冲突

传统 AI Coding 工具通常游离在研发流程之外，而真正的升级是让 AI 成为流程中的原生节点。

## 最终封面文案

```text
AI终于
进流程了
```

唯一高亮：`进流程`

## 构图

选择 C：极简流程图 + 结果。

- 左侧：大面积两行标题
- 右侧：极简 Git 工作流
- Git 仓库作为核心节点
- AI NPC 明确嵌入流程内部
- 流程最多 5–6 个节点
- 一个小证据标签：`Git原生记忆 / 工程化协作`

## 视觉逻辑

```text
需求
 ↓
Git仓库 → 代码评审
 ↑          ↓
交付 ← PR合并

AI NPC 嵌入 Git / Review / PR 流程内部
```

不要做成完整软件架构图；观众只需要一眼感受到“AI 不再在流程外，而是在流程内工作”。

## 配色

- 黑色背景
- 白色主标题
- 青绿色强调“进流程”以及 AI 节点
- 少量橙色用于 Git / 工程节点

## 证据

`Git原生记忆 / 工程化协作`

它证明这不是普通 Chat UI 或单点 Coding Assistant，而是基于 Git 的工程化协作方式。

## 生成提示词核心

设计一张高点击率中文 YouTube 技术视频封面，主题为 AI 真正进入企业研发工作流。左侧使用超大两行中文标题“AI终于 / 进流程了”，只有“进流程”使用高亮青绿色，其余白色。右侧是极简、清晰的 Git 研发工作流，5–6 个节点以内，Git仓库为核心，AI NPC 明确嵌入 Git、代码评审、PR 合并与交付流程内部。增加一个很小的辅助证据标签“Git原生记忆 / 工程化协作”。黑色低干扰背景，大量留白，手机缩略图清晰，整体专业、高级、克制、真实，不使用随机机器人、蓝紫赛博朋克背景、粒子、电路、复杂架构图、大量 Logo 或密集小字。16:9 构图，同时适配 4:3 安全裁切。
