# 爆款视频创作 SOP（科技/工具类教学视频）

## 目的

引导用户从零完成一条科技/工具类教学视频的完整创作。核心方法论：`references/production-spec.md`（七段式结构 + 钩子系统 + 画面规范），创作前必读，所有产出必须严格遵守该规范。

**核心工作方式：阶段门禁（Stage-Gate）。绝不一次性生成全部文档——每个阶段只讨论/产出本阶段内容，用户明确确认后才进入下一阶段。**

## 触发场景

- 用户说"帮我写/创作一个视频脚本/口播稿/视频大纲"
- 用户要制作教程、产品演示、工具测评类视频
- 用户提到"爆款视频""按之前的规范做视频"
- 用户说"继续上次那个视频"→ 找到对应项目目录，从最近一个未确认的阶段继续

## 阶段总览

```
阶段1 选题与大纲 →【用户确认】→ 阶段2 口播稿 →【用户确认】
→ 阶段3 素材/画面/分镜 →【用户确认】→ 阶段4 标题与封面 →【用户确认】
→ 阶段5 验收找茬（视频完成后）
```

每个阶段结束时：落盘保存 → 用 present_files 呈现本阶段产物 → 明确询问"是否确认进入下一阶段？"。用户提出修改意见则在本阶段迭代，直到确认。

## 执行流程

### 第 0 步：建立产物目录与进度文件

在当前工作区创建 `video-projects/<项目名>-<日期>/`，并创建 `00-进度.md` 记录各阶段状态（未开始/进行中/已确认）。每完成一个阶段立即更新该文件——这是跨会话续作的依据。

### 阶段 1：选题方向与视频大纲

**先引导式提问**（用 AskUserQuestion，分批每批≤4题，禁止一次抛完；用户答"随便/你定"时基于参考案例自行决策并说明理由）：

- 第 1 批：主题/产品是什么？目标观众？平台与时长（建议8–12分钟）？核心目标（涨粉/转化/品牌）？
- 第 2 批：可演示的真实案例/素材有哪些（≥3个，用于递进案例链）？观众最痛的3个具体操作场景？可用的利益钩（免费/限时/独家）？有没有"反常识瞬间"可作名场面？

**产出 `01-视频大纲.md`**：选题定位（一句话）+ 七段式大纲表（每段起止时间、内容、钩子类型、所用素材、画面形式），案例链按"能用→好用→自动→万能→团队/生态"排序并标注名场面位置。

**门禁**：呈现大纲，与用户讨论选题方向是否成立、案例链排序是否合理，确认后才进入阶段 2。

### 阶段 2：口播稿（视频脚本）

基于已确认的大纲展开。**先补充提问**（≤4题）：是否真人出镜/口播还是配音？有无必须规避的内容或合规话术？语气偏好（极客玩梗/稳重专业）？

**产出 `03-口播稿.md`**：完整逐字稿，带时间码分段；密度 150±20 字/分钟；每 30–60 秒标注钩子类型；每案例标注数字锚点；标注先抑后扬处、名场面、金句；句间停顿与重音提示。写完后用规范禁忌清单自查修订一遍再给用户。

**门禁**：呈现口播稿供用户逐段确认/修改，确认后进入阶段 3。

### 阶段 3：素材、画面与拍摄（分镜）

基于已确认的口播稿。**先提问**（≤4题）：录屏素材是否已有/需补拍？动效制作能力（自己做/外包/不要动效）？字幕样式偏好？

**产出 `04-画面分镜表.md`**：逐段分镜表：时间段 | 口播摘要 | 画面内容 | 画面类型（标题卡/动画图解/录屏/特写）| 剪辑要求（等待剪掉、加速倍数）| 字幕要点。硬性检查：任意 20 秒内必有画面变化。
**产出 `05-制作清单.md`**：拍摄/录屏/素材/动效/字幕/发布 checklist。

**门禁**：用户确认分镜后进入阶段 4。

### 阶段 4：标题与封面

放在素材分镜之后定稿（此时对成片内容把握最准）。**产出 `02-标题与封面.md`**：3 版候选标题（公式：震撼角色/结果 + 悬念/新概念 + 品类词）+ 3 版封面方案（大字 ≤10 字、配色、主视觉描述），标注推荐项及理由。

**门禁**：用户选定标题封面后，全部创作阶段完成，更新 `00-进度.md`。

### 阶段 5：验收找茬

**时机：视频制作完成后**（而非文档完成后）。用户带着成片/终稿回来时，调用 viral-video-reviewer 的流程对成片对应的稿件（口播稿+分镜+标题封面）做规范验收，产出验收报告并修订。

若用户在阶段 2–4 中主动要求"先验收一下文档"，也可提前运行，但默认验收在视频完成后进行。

### 交付

每个阶段结束用 present_files 呈现该阶段产物；全部完成后一次性呈现全部产物 + 3–5 条核心创作要点。

## 硬性规则

- 阶段门禁不可跳过：未获用户明确确认，不得生成下一阶段的文档。
- 所有产物必须落盘保存，不允许只在对话中输出；每阶段结束更新 `00-进度.md`。
- 口播稿禁忌："大家好我是"、空洞自夸、超 2 秒无信息停顿、"然后"连用。
- 每个案例至少 1 个具体数字锚点；全文至少 1 处先抑后扬、1 个名场面、1 句 ≤30 字金句。
- 用户信息不足时先做合理假设并在文档中标注【假设】，不要因缺信息而停手。
