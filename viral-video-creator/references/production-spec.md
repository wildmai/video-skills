# 通用爆款视频制作规范（科技/工具类教学视频）

> 来源：从 B 站同题爆款对比分析中提炼（技术爬爬虾《CodeBuddy NPC全攻略》2天8.7万播放/13%点赞率 vs 同类视频2千播放）。
> 本文件是创作与验收的唯一规范来源（single source of truth）。

## 1. 七段式爆款大纲结构

| 段落 | 时长占比 | 任务 | 硬性要求 |
|---|---|---|---|
| ① 钩子 | 0–15 秒（≤5%） | 结果前置：直接展示最终最惊艳的画面/一句话承诺 | 禁止自我介绍、片头动画超过 3 秒、"大家好我是XXX" |
| ② 痛点 | 5–10% | 描述目标观众正在忍受的具体场景 | 必须是"动作级"描述（"复制报错→粘贴→再报错"），不是抽象概念 |
| ③ 方案+卖点 | 10–15% | 主角登场 + 3 个以内核心卖点（含 1 个利益钩，如限时免费） | 卖点 ≤3 个，每个一句话 |
| ④ 路线图 | ≤5% | 一句话告诉观众接下来会看到什么 | 给观众确定性，降低跳出 |
| ⑤ 递进式案例 ×3–5 | 50–65% | 核心内容，按"认知升级链"排序：能用→好用→自动→万能→团队/生态 | 后一个案例必须比前一个"更厉害"；案例间用"先抑后扬"或悬念衔接；至少 1 个"名场面" |
| ⑥ 升华 | 5–8% | 从产品价值升到行业趋势/方法论，产出 1 句可截图传播的金句（优先排比句式） | 金句 ≤30 字 |
| ⑦ CTA | ≤3% | 低压力行动号召：开源地址/评论区/关注 | 只有一个动作 |

## 2. 钩子系统

- **第一句即钩子**：格式 =「动作 + 惊艳结果」，如"只需要在仓库里@一下，就能召唤一支AI员工团队"。
- **钩子类型**：结果前置钩 / 利益钩（限时免费等稀缺性）/ 预期钩（承诺具体内容）/ 悬念钩（先抑后扬）/ 好奇钩（"还能这么玩？"）。
- **密度**：每 30–60 秒埋一个钩子，形成钩子链，防止中段流失。

## 3. 脚本/口播稿规范

- **逐字稿先行**：口播稿先写成文字，密度 150±20 字/分钟，删掉所有不产生信息的句子后再录制。
- **数字锚点**：每个案例至少 1 个具体数字（57 个文件、48GB 显存、省 90% token）。
- **拟人化命名**：工具叫"员工/伙伴"，流程叫"招聘/汇报/协作"。
- **先抑后扬**：至少设计 1 处"主动暴露不足→展示解决"，可信度倍增。
- **金句收尾**：用排比/对仗产出一句话总结（≤30 字），可截图传播。
- **禁忌清单**：无"大家好"、无"本期视频非常干货"、无超过 2 秒的无信息停顿、避免"然后……然后……"口头语。
- **配音要求**：语速偏快、句间停顿 ≤0.5 秒、重点词加重音、忌匀速念稿。

## 4. 标题与封面规范

- **标题公式**：`[震撼角色/结果] + [悬念/新鲜概念] + [品类词]`
  - ✅ 「开发团队AI员工，下一代Agent：CodeBuddy NPC全攻略」
  - ❌ 「从0开始，让AI融入你的研发流程」（功能描述，无画面、无悬念、无利益）
- **封面**：大字 ≤10 字 + 高对比色 + 产品界面/角色形象；优先放"结果画面"而非 logo。
- 出 3 版候选再定稿。

## 5. 画面制作规范

| 项目 | 规范 |
|---|---|
| 片头 | ≤3 秒，黑底大字标题卡或梗图，直接进钩子 |
| 节奏 | 任意 20 秒内必须有镜头/场景切换；整片场景切换 ≥3 次/分钟 |
| 录屏 | 只保留"输入→关键操作→结果"；等待过程全部剪掉或 ≥4 倍速；鼠标路径提前规划；分辨率 ≥1080p |
| 概念表达 | 抽象概念一律用动画图解/角色卡，不空口讲概念 |
| 演示设计 | 案例结果要"可视化"：运行中的系统、测试全绿、代码行数统计 |
| 名场面 | 每期至少 1 个"反常识瞬间"（如 AI 纠正 AI），留足 10 秒以上特写 |
| 字幕 | 全程硬字幕，与口播严格同步；章节处加大字标题卡 |
| 收尾画面 | 给出可行动的具体路径（开源地址/命令），而非"感谢观看" |

## 6. 发布与复盘

- 发布时间：工作日晚 18–22 点或周末。
- 发布后前 2 小时回复所有评论拉互动。
- 复盘：看完播率曲线，流失峰值处即为下期改进点。

## 7. 验收检查单

- [ ] 前 15 秒是否出现"最终惊艳结果"？
- [ ] 删掉开头能否直接进入内容？（能 = 开头有废话）
- [ ] 案例是否按"后一个比前一个更厉害"排序？
- [ ] 是否至少 1 处"先抑后扬"和 1 个"名场面"？
- [ ] 是否每 30–60 秒有一个钩子？
- [ ] 是否至少 3 个具体数字锚点？
- [ ] 是否有可截图传播的金句（≤30 字）？
- [ ] 任意 20 秒是否都有画面变化？等待画面是否清零？
- [ ] 标题是否包含"角色/结果 + 悬念 + 品类"三要素？
- [ ] CTA 是否只有一个动作且有具体路径？

## 8. 参考案例（爆款标杆）

技术爬爬虾《开发团队AI员工，下一代Agent：CodeBuddy NPC全攻略》（11'44"）：
- 0:00 钩子（结果前置8秒）→ 0:08 痛点对比 → 0:21 方案+卖点（免费钩）→ 1:10 路线图
- 案例链：单NPC(能用) → 定制NPC(好用) → 事件驱动NPC(自动) → GPU/OCR NPC(万能) → NPC团队协同+自我纠错(名场面)
- 11:04 升华金句（"Issue成为需求记忆，PR记录决策记忆，CI保存质量记忆，代码库承载最终成果"）→ 11:33 CTA（开源地址）
