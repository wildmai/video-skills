# 制作细则

阶段执行中按需查阅。

## 录制（由用户完成）

技能不录屏。用户用 OBS / ShareX / 系统录屏等工具录制，技能只负责操作与后期。

1. **先把录制方案问清楚**：用什么工具、录哪块屏、录窗口还是整屏、是否录系统声音、输出格式与分辨率。
   录整屏时把无关应用关掉或最小化；技能也可以用 `prep` 帮忙藏窗口。
2. **录制前开启守卫**：`studio guard start --project <项目> --protect "<目标程序标题>"`。
   技能在操作过程中执行的命令、以及其它程序弹出的控制台和输入法浮层，
   都会被守卫立刻藏掉——它们本来会被录进画面。
   操作结束后 `studio guard stop` 恢复窗口，并用 `studio guard status` 确认采集屏干净。
3. **建议按章分段录**：一次录一个功能，素材好管理、补录代价小。
   一次录全流程也行，靠索引定位。
4. **原生分辨率录制**：外部工具直接抓显示器的原始输出，文字锐利；
   技能内建抓屏只能拿到合成后的画面，高分屏上会发虚——所以不要用内建抓屏当素材。
5. **录制前留 2 秒静止**：给剪辑留出干净的起幅。
6. **录制后留 2 秒静止**：给收尾留余量。
7. **操作完成立刻让用户停录**，不要让用户多录一堆等待和发呆。

## 操作

1. **先通知用户开始录制，等用户确认后再动手。** 否则准备动作会被录进去。
2. 一次录完整流程时，在章节之间**短暂停顿**，让剪辑有清晰的切点。
3. 浏览器操作走 CDP 元素点击：它**不移动真实鼠标**，录制里看到的指针不会乱跳。
4. 需要真实鼠标时，提醒用户录制期间不要动鼠标。
5. 控件屏幕坐标 = 元素视口坐标 + 浏览器 chrome 偏移。标定一次，整段复用。
6. 操作位置用 `studio aim <项目> <x> <y> --note "..."` 记下来，
   后期把标注精确放在那个控件上。
7. 需要确认状态时，自己抓一帧：`studio shot --out check.png`，不必打断用户。
8. **登录、授权、验证码**：保持录制，由用户完成，技能只确认是否成功。
   剪掉凭据、验证码、密钥和私有数据——可以分段录制再按依赖顺序拼接。
9. 每一步都要保证画面上**看得见结果**，而不只是「点了一下」。

## 口播

1. 开头先给成果，再回到操作。第一个画面就是最有辨识度的东西。
2. 每段只讲**一个**操作重点。提到控件时，视线/光标落在那个控件上。
3. 边缘功能一句话带过；篇幅给「决定结果的那几个参数」和「怎么确认做对了」。
4. 数字、版本、价格、容量一律**从真实界面读到再写**。
5. 代码、配置、提示词放 ``` 围栏代码块——不会被念出来，只作画面。
6. `## ` 标题切章，章节标题同时是 `plan.json` 的章节 `id`，必须完全一致。

## 配音

1. Edge TTS，按段合成，段落文本和音色/语速都不变就复用缓存。
2. 合成后读入**实际音频长度**再排时间线，不要按字数估算。
3. 检查每段的 `chars/s`：低于 3.0 说明合成异常，改写后重生成。
4. 试听句首、句尾、专有名词和章节衔接。
5. 术语发音可以在合成文本上做微调，但画面里的字幕仍用产品正确名称。

## 剪辑

1. **先读索引再排镜头**：`build/index_<名字>.txt` 里有每一秒的画面文字和变化点，
   凭印象猜时间码是这类项目最容易翻车的地方。
2. **一个镜头服务一个操作重点**，镜头长度由那句口播决定。
3. 名称出现前或同时到达相应控件；关键反馈出现时留阅读时间。
4. 相邻控件尽量共用一次取景，不要频繁跳。
5. 合理压缩真实等待，但保留「触发动作 → 处理反馈」可辨认的时间。
6. 缺画面的段落，改写成画面能证明的话，或者让用户补录。
7. 章节标题卡、标注、推近按 `plan.json` 自动叠加；标注跟着它服务的那句话走。
8. 章节之间用交叉溶解，不要硬切。
9. BGM 铺底并压低给人声让位；关键瞬间可以保留现场音。
10. 剪掉无意义的停顿，保留有内容的停顿。
11. 用户录进来的**系统原声**（点击声、提示音）通常值得保留，比无声更可信；
    剪的时候不要把它整段切掉。

## 混音

1. 侧链压低在 numpy 里做：人声短时 RMS → 快速下压、慢速恢复的增益曲线。
2. `amix` 必须 `normalize=0`，否则每路输入被除以输入数量。
3. 响度目标 **−16 LUFS**，真峰 **≤ −1.5 dBFS**。
4. 归一化后补 `-ar 48000`。

## 验收

1. 文件能完整播放，时长符合需求，画面与声音轨道完整。
2. **逐帧 OCR 审计出片的每个窗口**——控制台路径、通知气泡、启动页、浮层，零容忍。
3. 以正常速度看和听整片，重点回查：前 3–10 秒、每个功能切换、提交与成果、
   数字专名、等候段、结尾。
4. 检查每个讲解点是否找得到对应光标落点；有没有大段静态换图、无内容停顿、
   BGM 盖人声、演示版和展示版混用。
5. 修正后重放涉及的前后段落，再重新导出并复验。
6. 记录哪些环节是补录的，补录原因写清楚，便于下一版直接复用干净区间。
